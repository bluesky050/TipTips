# 红色卡片与字体美化方案（已确认）

## 2026-10-12 配色调整（用户直接指定）

- 普通待办继续红色，官网及结构化手动宣讲会卡片改为浅黄色 `#fffbeb`，悬停 `#fef3c7`，使用琥珀色边框与深棕色文字。
- 深色模式对应暗黄色背景和浅金色文字；字体与布局保留。
- 官网同步栏与日历宣讲标识使用同一黄色主题。日期同时有未完成普通待办和宣讲会时，日期底色保留红色、宣讲数量标识黄色，避免隐藏任一类别。
- 不改变官网只读、手动编辑、完成或同步逻辑。

以下为此前确认的初版方案，配色以上述调整为准。

## 目标

统一列表和日历详情中的待办、官网宣讲会卡片为红色背景，改善中文字体与信息层级。

## 推荐方案：浅红卡片

- 浅色模式使用浅红背景 `#fff1f2`、红色边框 `#fda4af`、深色正文；悬停使用稍深的 `#ffe4e6`。
- 深色模式使用暗红背景与浅色文字，保持时间、地点和操作按钮可读。
- 待办和宣讲会使用相同卡片配色，通过“日程”和官网来源标识区分；已完成事项也保持红色底，通过勾选与标题划线体现完成。
- 日历中有宣讲会的日期增加红色背景与红色数量标识；有未完成待办的日期沿用统一红色配色，完成进度仍表达原有状态。
- 界面强调色统一为柔和的玫瑰红，配合圆角、细边框与适度留白。
- 使用本机字体栈：`Segoe UI Variable Text`、`Segoe UI`、`Microsoft YaHei UI`、`PingFang SC`、`sans-serif`；输入框和按钮继承字体，无需安装或下载字体。
- 卡片标题约14px、600字重；时间与地点约12px、行距1.65；来源信息约11px，避免过小或过淡。日期和时间使用等宽数字。

## 备选方案

深红实底配白字更醒目，但多条长日程一起显示时视觉更重；本次推荐浅红卡片。

## 范围与验证

- 仅调整样式和日历日期的样式标记，沿用现有查看、编辑、完成、官网只读与同步逻辑。
- 不修改个人数据、凭据或数据库结构，不删除文件。
- 运行现有界面测试、TypeScript检查与发布构建；用合成内容检查浅色/深色、长标题、完成状态和官网卡片。
- 构建新版可执行文件并保留现有程序备份；验证启动后更新现有入口。
