# SEU Official Calendar Implementation Plan

**Goal:** 按已确认的 docs/seu-calendar-proposal.md 接入东南大学官网今天及未来的只读宣讲日程，排除邮件宣讲会。

**Architecture:** 独立 Rust seu_fairs 模块处理公开接口分页、转换、缓存；commands 合并只读视图。Vue 共享同步状态组件，日历和列表区分官网日程与可编辑待办。复用已有 Schedule，不修改个人待办数据结构。

**Tech Stack:** Tauri 2、Rust reqwest/serde/chrono（现有依赖）、Vue 3。

## Constraints

- 不删除文件、历史邮件记录或已有备份，不修改凭据。
- 网络请求不进入同步的视图查询命令；后台线程执行，失败保留上次成功快照。
- 不因旧日期提前停止分页；以稳定网站ID去重，不以公司名去重。
- 未成功的分页/格式错误不能被表示成成功空列表。
